# Roadmap

## Version 1

Complete the ASP.NET Core/SQL Server backend and React/React Native clients for student and alumni community workflows.

## Version 2

Add an Angular client and living/settlement support: accommodation discovery, cost, distance, availability, room/inclusions, eligibility, dates, bond, maps and booking links. Reuse the backend and database where practical.

## Version 3

Add a Vue client on the same API.

## Future

Consider selective NoSQL for feed denormalization, notifications, messaging, or event streams. AI recommendations/search/summarization are future work and are excluded from V1.
